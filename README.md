# 專案派工進度 Dashboard

> 目前版本：v2.3.1

用來填寫工作紀錄、查詢員工工時、管理專案進度與檢視加班統計。詳細操作請參閱 [使用手冊](使用手冊.md)；版本變更請查看 [GitHub Releases](https://github.com/neilyonglu/proj-dashboard/releases)。

## 開啟系統

已設定好的本機環境可用 `uv run app.py` 啟動，再開啟 <http://127.0.0.1:5001>。使用 server 時，請開啟管理者提供的網址；主機 port 依部署設定。

環境安裝、GitHub Actions 與 server 部署步驟請參閱 [開發與部署指南](docs/MAINTAINERS.md)。

## 首頁

上方顯示進行中專案數（含逾期數）、本月總時數（較上月）與登錄員工數（本月已填報人數）。下方有四個功能入口：

| 入口 | 用途 |
|---|---|
| 工作內容填表 | 新增員工的工作時數與內容 |
| 員工表 | 查看個人工時紀錄與專案分佈 |
| 專案進度表 | 查看專案清單、詳情與時間軸 |
| 加班統計 | 依日期區間統計日班、加班與夜班時數 |

每一頁最上方都有共用頁首：主選單、外觀切換鈕、管理者入口與版本號。外觀預設為深色，切換鈕依序切換淺色、深色、跟隨系統，選擇記在瀏覽器。頁首的「管理者登入」輸入 `.env` 中的 `DB_ADMIN_PASSWORD` 後，直接進入資料庫管理；登入後該入口顯示「資料庫管理」。

## 新增工作紀錄

1. 點「工作內容填表」，從清單選擇參與人員與專案；輸入文字可篩選選項。
2. 填入工作日期與工作內容。
3. 填寫日班、加班、夜班時數（至少一項大於 0；1 天 = 8 小時），視需要填備註，再按「送出」。

新增工作紀錄只列出在職人員。編輯既有紀錄時，會保留該紀錄原有的離職人員選項。人員名單統一從 DB 管理頁維護。

## 員工表

選擇員工後可查看工作紀錄、總時數、參與專案與專案分佈圓餅圖；紀錄中的專案名稱可點進專案詳情。紀錄可依全部、年、月、週或日顯示，並展開／收合各組。

員工選單只列在職人員；從專案或既有連結仍可開啟離職人員的紀錄。一般使用者可查看與編輯，刪除需登入管理者。

## 專案進度表

- 右上角「新增專案」可建立專案；專案名稱可點進詳情頁，查看人員工時與紀錄。
- 專案表可搜尋（Ctrl+K）、篩選月份、業務代表、人員與狀態；狀態可複選，也可點上方狀態數量標籤切換。
- 專案詳情的工作紀錄可搜尋、分頁並匯出 CSV。
- 時間軸可查看工期與每日人員紀錄（同一天合併一格），滑鼠移到（手機點一下）可看日期、人員與內容。
- 點擊人員名稱可進入員工表。離職人員會有離職標示。

刪除專案需管理者權限。專案若還有工作紀錄，會先列出這些紀錄（可逐筆編輯改到其他專案），選「強制刪除」並再次確認後，才會連同紀錄一起刪除。

## 加班統計

選擇日、月、年或自訂日期區間，即可查看各員工與各專案的日班、加班、夜班時數，依加班時數由高到低排序，並可匯出 CSV。

統計取自工作紀錄的「時數明細」；未填時數的紀錄不會換算成時數。

## 資料庫管理

登入管理者後，可使用專案、工作紀錄、業務代表、參與人員與專案種類五個分頁，搜尋與維護資料；每頁顯示 50 筆。刪除、還原與清空匯入都會先跳出確認視窗。

- **人員名單**：「參與人員 → 管理參與人員」可新增、修改名稱、大頭貼、離職日期或移除人員。
- **業務代表**：「業務代表 → 管理業務代表」可新增、修改、設定離職日期或移除。
- **離職狀態**：參與人員與業務代表分頁保留完整名單，顯示在職／已離職及日期。清空離職日期並儲存即可恢復在職。
- **專案種類**：從對應管理按鈕新增、修改或移除種類。

人員代號改名會同步更新工作紀錄；業務代表或專案種類改名會同步更新關聯專案。業務代表設定離職日期不會自動移除專案表單中的選項。

## 匯入、匯出與備份

- **CSV**：各分頁可匯出或匯入單一資料表，支援 UTF-8／BIG5；匯入可選略過重複或覆蓋更新。
- **Excel**：「全部匯出／全部匯入」處理完整資料庫，每張資料表各一個分頁。
- **離職日期**：人員與業務代表的 CSV／Excel 包含此欄，接受 YYYY-MM-DD 或 YYYY/MM/DD。覆蓋更新時，空白日期會恢復在職；舊檔未含此欄則保留既有日期。
- **備份**：系統每天自動備份一次，保留最近 10 份（頁首右上角會顯示「上次自動備份」時間）；後台可立即備份、下載 `.db` 或還原備份。

匯入前清空資料與還原備份會改動現有資料；系統會先自動備份。刪錯資料時可使用先前備份還原。

本機資料庫、備份與日誌位於 `instance/`；Docker 的主機資料位於 `data/instance/`。大頭貼分別位於 `static/avatars/` 與 `data/avatars/`。操作日誌放在對應資料目錄的 `logs/` 中。
